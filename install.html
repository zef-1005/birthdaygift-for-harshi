Phone (Android) Installation Guide

Follow these easy steps to get started

1

Open the Google Drive Link

Click the button below to access the Android folder.

Open Android Drive Folder
2

Download the APK File

Inside the folder, tap on the APK file and select Download.

3

Allow "Install Unknown Apps"

If your browser or device prompts a security message, tap Settings on the popup and turn on "Allow from this source" (or enable "Unknown Sources").

4

Install and Open

Open the downloaded file from your notifications or Downloads folder and tap Install.

PC / Desktop (Windows) Installation Guide

Follow these easy steps to get started

1

Open the Google Drive Link

Click the button below to access the PC / Windows folder.

Open Windows Drive Folder
2

Download the File

Download the installer or zip file from the Google Drive folder onto your PC.

3

Run the Setup File

Go to your Downloads folder and double-click the file to open and run it.

4

If Windows SmartScreen Appears

If a blue popup says "Windows protected your PC", click "More info" and then click "Run anyway".
